# Grade Statistics Calculator

A Java program that calculates important statistics for a class of 10 grades.

## Features

- Reads 10 floating-point grades from user input
- Input validation (grades must be between 0-100)
- Calculates and displays:
  - Average grade
  - Maximum grade
  - Minimum grade

## How to Run

1. Compile the program:
   ```
   javac Grade_Stats/GradeCalc.java
   ```

2. Run the program:
   ```
   java Grade_Stats.GradeCalc
   ```

3. Enter 10 grades when prompted

## Example Output

```
Enter 10 grades:
Enter grade 1: 85.5
Enter grade 2: 92.0
...
Enter grade 10: 78.5

Grade Statistics:
Average: 84.50
Maximum: 92.00
Minimum: 78.50
```

## Requirements

- Java JDK 8 or higher
